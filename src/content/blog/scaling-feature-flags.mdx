## Context

As flag counts grow, teams need ownership boundaries and expiration policies.

## Practices that worked

- Define flag classes: release, ops, experiment.
- Require owner and cleanup date.
- Alert on stale flags in CI.

## Outcome

Governance cut rollback incidents while keeping release velocity steady.

```ts
export function assertFlag(flag: { owner?: string; expiresAt?: string }) {
  if (!flag.owner || !flag.expiresAt) {
    throw new Error("Invalid flag metadata");
  }
}
```
