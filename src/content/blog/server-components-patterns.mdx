## Why this matters

Server Components reduce shipped JavaScript and simplify data-fetching boundaries.

## A decision rule

1. Start with server rendering by default.
2. Promote to client only when stateful interactivity is required.
3. Keep client islands narrow.

### Example split

Use server-rendered product grids and lazy client filters to preserve performance.
